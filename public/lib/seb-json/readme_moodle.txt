SEB-JSON
--------

Downloaded from: https://github.com/cameron1729/seb-json/releases/tag/v1.1.0

Import procedure:

* Update the exact cameron1729/seb-json version in composer.json, then update composer.lock with Composer.
* Replace LICENSE, README.md, composer.json and src in public/lib/seb-json with the files from vendor/cameron1729/seb-json.
* Update the version in public/lib/thirdpartylibs.xml and the release URL in this file.
* Run `npx grunt ignorefiles`.
